# Changelog

## 0.1.0 — 2026-11-08

The first RockxyBit macOS release adds a request workbench for creating, replaying, organizing, and inspecting API requests. It can import cURL, HAR, Postman, OpenAPI, SoapUI, and selected Rockxy captures, then export reviewed rule files for Rockxy.

The app includes a free tier. Pro Standard and Pro Personal licences add comparison, request variants, environment matrix, runner, mock server, and Rockxy handoff capabilities.

Requires macOS 26.2 or later. The download is Developer ID signed and notarized.
