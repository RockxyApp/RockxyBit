# Support

Use [GitHub Issues](https://github.com/RockxyApp/RockxyBit/issues) for reproducible bugs and feature requests. Include the RockxyBit and macOS versions and steps using disposable sample requests.

Remove tokens, cookies, authorization headers, API keys, private hostnames, local account paths, request and response bodies with real data, and licence details from text, screenshots, and attachments. For a vulnerability, follow [SECURITY.md](SECURITY.md) instead of filing a public issue.
