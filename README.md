# RockxyBit

RockxyBit is a proprietary macOS workbench for API requests and responses. Its source code is private. This repository is for release downloads, update metadata, and product support.

Download RockxyBit 0.1.0 from [Releases](https://github.com/RockxyApp/RockxyBit/releases). The `appcast.xml` file carries signed update entries.

For a bug or feature request, use [Issues](https://github.com/RockxyApp/RockxyBit/issues). Read [SUPPORT.md](SUPPORT.md) first. Report vulnerabilities privately as described in [SECURITY.md](SECURITY.md).
