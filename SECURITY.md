# Security

Report suspected vulnerabilities through a [private GitHub Security Advisory](https://github.com/RockxyApp/RockxyBit/security/advisories/new). Do not open a public issue containing a vulnerability or secret.

Use disposable endpoints and sample data for reproduction. Remove API keys, authorization headers, cookies, private hosts, account paths, request and response bodies with real data, and licence details from the report and attachments.

The latest published RockxyBit release is the supported version. There is no published release yet.
